# SceneTheme - 用场景管理游戏主题

<img width="1291" height="939" alt="1" src="https://github.com/user-attachments/assets/e9e2eeec-6da1-4284-b423-00f028e6e731" />

将主题编辑的工作, 从杂乱的主题编辑器中解放出来

在场景界面中编辑、预览和管理主题，更直观、更自由。

## 特性
  - 自由布局: 多类型同时查看与编辑

  - 节点复用: 复制节点即可直接使用

  - 即时预览: 运行场景实时查看主题效果
  
## 局限
  - 不支持自定义属性(完全没用过)

## 注意
Godot 4.4 以下的某些版本不支持主题热重载

修改主题后可能需要重启编辑器, 子节点主题栏属性中的[类型变种]才会更新选项。

## 安装
1.下载源码压缩包

2.将 addons 文件夹中的内容复制到你的项目目录

3.在编辑器插件列表中启用 [- Scene Theme]

## 使用方法
1.在场景树中右键点击任意 Control 节点

2.选择上下文菜单中的 [SceneTheme]

3.配置弹出窗口中的选项
  - 节点前缀: 从所选节点向下遍历, 只匹配包含此前缀的节点（不跨场景）

  - 类型移除前缀：保存主题类型名时自动移除节点前缀

  - 保存: 选择路径并生成主题预设文件
